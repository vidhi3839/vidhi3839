## Projects

### [Product Analytics Case Study: Reducing Checkout Abandonment](#)
`BigQuery` `SQL` `Python` `Power BI` `A/B Testing`

Analyzed **4.3M+ Google Analytics 4 events across 333K+ user sessions** using BigQuery SQL and Python to identify purchase-funnel bottlenecks. Built a session-level funnel segmented by user type, device, geography, and acquisition channel, identifying checkout completion as the primary friction point for new users.

Applied **Chi-square tests, Mann–Whitney U tests, and 95% confidence intervals** to evaluate conversion differences and designed a production-style A/B experiment including success metrics, guardrails, power analysis, MDE, and sample-size calculations.

---

### [Customer Churn Prediction](#)
`Python` `Scikit-learn` `Random Forest` `Customer Analytics`

Built a **Random Forest churn prediction model achieving 0.87 ROC-AUC** using demographic, contract, and billing features. Exploratory analysis identified customer tenure, contract type, and monthly charges as key churn drivers.

Engineered customer-level features, evaluated ROC-AUC and F1-score, and ranked churn probabilities to create a **customer risk segmentation strategy** for targeted retention campaigns.

---

### [Retail Demand Forecasting & Price Optimization](#)
`Python` `PyTorch` `Time Series` `Feature Engineering`

Processed **1.06M+ retail transactions** into 159K+ weekly product records across 3,139 products and engineered 30 time-series features including lag variables, rolling statistics, seasonality, and price elasticity.

Developed and compared **5 forecasting models**, with a PyTorch Deep Neural Network achieving **R² = 0.9513** on a temporal holdout dataset. Built a price optimization framework using predicted demand to estimate revenue-maximizing prices and evaluated prediction uncertainty using bootstrap sampling.

---

### [AI Resume Matching Platform](#)
`Python` `Sentence-BERT` `Flask` `React` `MongoDB` `Gemini API`

Fine-tuned **Sentence-BERT on 9,544 expert-labeled resume–job description pairs**, improving semantic job-matching performance to **R² = 0.6964** and outperforming TF-IDF, pretrained SBERT, and Random Forest baselines.

Built an end-to-end resume screening application using **Flask, React, MongoDB, and Gemini API** to automate resume parsing, semantic matching, and recruiter-facing candidate ranking.
